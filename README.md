# gitparty

Este projeto é um sistema que organiza as incrições, usuariose e eventos de um estabelicimento

## Funcionalidades

- Criar usuario
- Editar usuario
- Excluir usurio
- Listar usuario
- Buscar usuario
- Criar eventos
- Listar eventos
- Editar eventos
- Buscar eventos
- Excluir eventos
- Listar inscrições
- Editar inscrições
- Buscar inscrições
- Criar inscrições
- Excluir inscrições

  ## Tecnologias

- JavaScript
- HTML
- CSS
- Node
- Prisma

## Como usar

1. Clone o repositório:
2.Rode no terminal do vscode o backend e teste no insomia
3. Abre o site pelo index
